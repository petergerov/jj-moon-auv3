# Width

The breeze stereo trick, macro-controlled — third in the chain.

Micro-pitch (a few cents opposite L/R) plus short modulated delays on the band
*above* Focus, blended with a wet amount scaled from the Width knob. Below
Focus the signal stays dry and mono-compatible, so the acoustic body does not
wander across the stereo field.

## Controls

| Control | Range | What it does |
|---|---|---|
| **Width** | 0–100 % | Maps to ±cents, Delay L/R (roughly 9–25 ms), and wet mix (up to ~32 %). |
| **Focus** | 80–2000 Hz | Crossover. Everything below stays dry. Raise it to protect more of the body; lower for fuller-band width. |
| **On/Off** | | Bypass for Width only. |

## Defaults and presets

Default sits around 35 % Width / 220 Hz Focus — enough image for a close mic
without turning a mono DI into a chorus. **Stereo Porch** pushes Width hard;
**Close Mic** and **Piezo Soft** keep it restrained.

## What it is not

It is not a Haas pan, not a big chorus, and not a full-band pitch drop. For
room air see Space; for spectral shape see Curve.
